---
name: Catalogue draft media gate
description: Why unpublished catalogue drafting and product publication have different media completeness requirements.
---

Staff should be able to save an unavailable placeholder product before its photos, alt text, and provenance are ready. Publishing it is a separate decision that must still require complete, verified product media, even when the product is browse-only.

**Why:** Staff reported losing the ability to save a newly authored product because the editor initially creates it without images, while the document validator demanded completed media. Using unrelated placeholder photography or weakening public checks would hide the problem and risk publishing misleading content.

**How to apply:** Keep incomplete-media tolerance limited to unavailable draft placeholders, preserve partial image-row edits between saves, and reject missing media before publication. Continue validating any real asset paths and file bytes already supplied.
